✅ Smart To-Do App with Sound & Dark Mode 🌙🎵



A modern, interactive Smart To-Do List Web App built using pure HTML, CSS, and JavaScript.
It includes sound feedback, dark mode, filters, live stats, and local storage saving — all without any library!

🚀 Features

✅ Add new tasks
✅ Tap to mark tasks completed
✅ ✅ Tick icon replaces ❌ delete on completion
✅ Delete active tasks
✅ Clear completed tasks
✅ Live task statistics
✅ Filters: All | Active | Done
✅ Dark Mode with smooth animation
✅ Web Audio API 0.8s completion sound
✅ localStorage auto-save
✅ Keyboard support
✅ Mobile responsive

🛠️ Technologies Used

HTML5 – Page structure

CSS3 – Styling, animations, dark mode

JavaScript (Vanilla) – Functionality

Web Audio API – Sound

localStorage API – Persistent storage

🎯 How to Use

✍️ Enter task → press + or Enter

✅ Click on task → marks as done + sound plays

✅ Tick appears instead of delete

❌ Delete only works on active tasks

🔍 Filter tasks using buttons

🧹 Clear all completed tasks

🌙 Toggle Dark Mode from top-right

🔊 Sound System

Built using Web Audio API:

Triangle waveform

Smooth fade in/out

Runs for 0.8 seconds

Safe loud volume

🌗 Dark Mode System

Smooth animation

Saves theme in localStorage

Reload-safe

Fully readable gray text fixed

💾 Persistent Storage

All task data is saved using:

localStorage.setItem()
localStorage.getItem()


Refreshing the page never deletes tasks ✅
